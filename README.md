# Sample Superstore Sales Analysis (Excel)

## Overview
An end-to-end data analysis project built in Excel using the Sample Superstore dataset. The project takes raw retail sales data through cleaning, transformation, and analysis, ending in an interactive dashboard and a summary of key findings.

## What's Inside
- **Raw Data** – the original Sample Superstore dataset
- **Data Cleaning** – standardizing formats, fixing inconsistencies, and preparing the data for analysis
- **Calculated Columns** – custom fields added to support deeper analysis (e.g. profit margin, order processing time)
- **Pivot Tables** – summarizing sales, profit, and other metrics across categories, regions, and time periods
- **Interactive Dashboard** – a single-view dashboard with slicers/filters for exploring the data dynamically
- **Findings Sheet** – a plain-English summary of the key insights uncovered in the analysis

## Tools & Skills Used
- Microsoft Excel (data cleaning, formulas, PivotTables, PivotCharts, slicers, dashboard design)
- Data visualization and dashboard design principles

## Key Challenges & Solutions
- **Date grouping** – resolved issues grouping transaction dates by month/quarter/year in pivot tables
- **Chart formatting** – fine-tuned chart formatting so the dashboard visuals displayed clearly and consistently

## How to Use
1. Download the `.xlsx` file from this repository.
2. Open it in Excel (enable editing/macros if prompted).
3. Use the slicers on the dashboard sheet to filter by category, region, or time period.
4. See the Findings sheet for a written summary of the key takeaways.
